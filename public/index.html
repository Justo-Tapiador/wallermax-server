Wallermax Server

A modular, secure and high-performance web server written in Rust.

>_
Status: v0.12.0 — the roadmap phases done, a dynamic template engine with require() running on the original node-jhs2 engine, browser sessions, and a small built-in CMS that owns the homepage, and a server-side proxy for external APIs.
♢

Secure

Built with modern security practices, including HTTPS (rustls), refresh tokens with family revocation, and trusted proxy X-Forwarded-For parsing.

ϟ

High Performance

A modular architecture with a multi-stage Docker image, compose example and GitHub Actions CI pipeline.

◇

Flexible & Modular

Template engine (jhs), dynamic require(), CommonJS modules, a server-side proxy for external APIs and more.

⚙

Built-in CMS

Database-backed pages at /p/<slug>, login/registration modals, and a JavaScript-free admin panel for content and accounts.

♙

Sessions & Identity

Browser sessions with wallermax_session cookie, user global in every render, and a no-JavaScript /login page.

⌁

Monitoring & Observability

Prometheus /metrics endpoint, GET /health and the wallermax_template_backend metric.

◷   Version History

A journey of continuous improvements.

Latest v0.12.0
v0.5.0

The sandboxed .jhs template engine.

v0.7.0

Keeps browsers logged in with the wallermax_session cookie and the no-JavaScript /login page.

v0.9.0

require() back to the templates — a native module bridge with a configurable forbidden-modules banner, the crypto polyfill, CommonJS modules under modules/, plus res.redirect() and the req global.

v0.10.1

Exposes the live backend through GET /health and the wallermax_template_backend metric.

v0.12.0

Adds the server-side external API proxy.

v0.6.0

Injects the authenticated identity into every render as the user global.

v0.8.0

Adds the CMS: database-backed pages at /p/<slug>, login/registration modals, a JavaScript-free admin panel for content and accounts.

v0.10.0

Moves every render onto a supervised Node sidecar running the original node-jhs2 engine ([templates] backend = auto | boa | sidecar).

v0.11.0

Gives the CMS the homepage: [cms] default_page renders a database-backed page at GET / — ahead of the static index file, with /p/<slug> draft gating and a graceful fallback.
